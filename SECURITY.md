# Security

Use only with endpoints you are authorized to diagnose. Live mode opens explicit connections; it does not discover subnets or port ranges. Reports contain target hostnames and ports. No credentials are requested or stored, and TLS verification cannot be bypassed through configuration.

Never deploy the public test key or install the test certificate into system trust. Private CA bundles are read only for the requested run. This initial release has no security support SLA. Use GitHub private vulnerability reporting if enabled; otherwise request a private reporting channel without posting sensitive details in an issue.
