# Contributing

Describe the operator problem and expected behavior in an issue. Keep code and documentation in English. Include tests for unavailable evidence and boundary conditions; run the complete suite before submitting a pull request. Preserve explicit targeting, verification defaults, and report compatibility.

Do not include real private infrastructure reports, credentials, or production certificate keys. The intentionally public loopback fixtures are documented separately. Licensing remains pending owner selection; discuss substantial contributions with the maintainer first.
